    required_files = [

    missing = [f for f in required_files if not os.path.exists(f)]
    
    if missing:

        print("Re-running discovery to regenerate missing files...")
    else:
        print("✓ All artifacts exist. Discovery already complete.")
        print("\nExisting artifacts:")
        for f in required_files:
            print(f"  - {f}")
        exit(0)

# ========================
# LOAD DATASET
# ========================
print("\n--- Loading Dataset ---")

# ========================
# DATASET PROFILING
# ========================
print("\n--- Profiling Dataset ---")

profile = {
    "dataset_id": DATASET_ID,
    "file_path": FILE_PATH,
    "shape": {"rows": int(df.shape[0]), "columns": int(df.shape[1])},
    "columns": list(df.columns),
    "dtypes": {col: str(dtype) for col, dtype in df.dtypes.items()},
    "missing_values": {col: int(df[col].isna().sum()) for col in df.columns},
    "numeric_columns": list(df.select_dtypes(include=['number']).columns),
    "categorical_columns": list(df.select_dtypes(include=['object', 'category']).columns),
    "memory_usage_mb": float(df.memory_usage(deep=True).sum() / 1024**2)
}

# Save profile
profile_path = f"{WORK_DIR}/dataset_profile.json"
with open(profile_path, 'w') as f:
    json.dump(profile, f, indent=2)
print(f"✓ Saved: {profile_path}")

# ========================
# SAVE DATASET HEAD
# ========================
head_path = f"{WORK_DIR}/dataset_head.csv"

# DISCOVER TARGET CANDIDATES
# ========================

    "column_name": candidates,
    "dataset_id": [DATASET_ID] * len(candidates)
})

candidates_df.to_csv(candidates_path, index=False)

# ========================
# LOG MM RECORDS
# ========================
print("\n--- Logging MM Records ---")

# 1. Dataset artifact
mm.rag_add(
    kind="dataset_artifact",
    text=f"Dataset profiled: {df.shape[0]} rows, {df.shape[1]} columns. Numeric: {len(profile['numeric_columns'])}, Categorical: {len(profile['categorical_columns'])}",
    meta={
        "dataset_id": DATASET_ID,
        "file_path": FILE_PATH,
        "state": "DISCOVER_DATASET",
        "artifact_path": profile_path,
        "shape": profile["shape"]
    }
)
print("✓ Logged: dataset_artifact")

# 2. Target candidates
mm.rag_add(
    kind="target_candidates",

    meta={
        "dataset_id": DATASET_ID,
        "file_path": FILE_PATH,
        "state": "DISCOVER_DATASET",
        "artifact_path": candidates_path,
        "candidates": candidates
    }
)
print("✓ Logged: target_candidates")

- **Predictive Value**: 2-year horizon aligns with typical pavement management system (PMS) planning cycles

**Why IRI over RUT**:
1. **Functional vs. Structural**: IRI measures what users experience; RUT measures structural capacity
2. **Budget Allocation**: Maintenance budgets are typically allocated based on ride quality (IRI), not just structural distress
3. **Regulatory Compliance**: Federal reporting requirements focus on IRI
4. **Deterioration Modeling**: IRI has well-established deterioration curves in pavement engineering literature

**RUT_2019 as Secondary Target**: ✅ RECOMMENDED for validation

### 2. IRI CONDITION THRESHOLDS (FHWA Standards)

Based on **FHWA guidelines** and typical state DOT practices:

| Condition Rating | IRI Range (m/km) | Pavement State | Typical Treatment |
|------------------|------------------|----------------|-------------------|
| **Excellent** | < 1.5 | New/recently rehabilitated | Routine maintenance |
| **Good** | 1.5 - 2.7 | Acceptable ride quality | Preventive maintenance |
| **Fair** | 2.7 - 4.3 | Noticeable roughness | Corrective maintenance |
| **Poor** | 4.3 - 5.5 | Uncomfortable ride | Rehabilitation needed |
| **Very Poor** | > 5.5 | Unacceptable | Reconstruction candidate |

### 3. PROBLEM TYPE RECOMMENDATION

**✅ PRIMARY: Regression (Continuous IRI Prediction)**

**Rationale**:
1. **Granular Decision-Making**: Continuous IRI values enable precise budget forecasting
2. **Treatment Optimization**: Exact IRI predictions allow cost-benefit analysis of different treatments
3. **Deterioration Rates**: Regression captures rate of change, not just threshold crossings
4. **Flexibility**: Can always convert continuous predictions to categories post-hoc

**Evaluation Metrics** (in priority order):
1. **RMSE (Root Mean Squared Error)**: Primary metric - penalizes large errors
   - Target: RMSE < 0.5 m/km (industry benchmark for good models)
2. **MAE (Mean Absolute Error)**: Interpretable error magnitude
   - Target: MAE < 0.4 m/km
3. **R² (Coefficient of Determination)**: Variance explained
   - Target: R² > 0.70 (acceptable for pavement models)
4. **MAPE (Mean Absolute Percentage Error)**: Relative error
   - Target: MAPE < 15%

**✅ SECONDARY: Classification (Condition Rating)**

**Use Case**: Maintenance prioritization and reporting
- **Classes**: Good (IRI < 2.7), Fair (2.7-4.3), Poor (≥ 4.3)
- **Evaluation**: Accuracy, Precision, Recall, F1-score
- **Practical Value**: Aligns with agency reporting requirements

**Engineering Justification**:
1. **Planning Cycle Alignment**: Most state DOTs operate on 2-year budget cycles

3. **Treatment Lead Time**: Allows time for project scoping, design, and procurement
4. **Model Stability**: Longer horizons (3+ years) introduce excessive uncertainty from:
   - Unplanned maintenance interventions

1. Load dataset and identify available columns
2. Create baseline condition features (polynomial, flags, interactions)

4. Create structural features (if age/type available)

### Phase 2: Feature Selection
1. Remove zero-variance features
2. Remove highly correlated features (r > 0.95, keep one)
3. Remove features with >50% missing values
4. Validate no leakage (temporal check)

### Phase 3: Feature Transformation
1. Handle missing values:
   - Numeric: median imputation (document in metadata)
   - Categorical: mode imputation or "Unknown" category
2. Encode categorical variables:
   - One-hot encoding for nominal (e.g., Pavement_type)
   - Ordinal encoding for ordered (e.g., Condition_rating)
3. Scale numeric features:
   - StandardScaler for features with normal distribution
   - RobustScaler for features with outliers
   - Log transformation for highly skewed features (AADT, traffic)

### Phase 4: Train/Test Split
1. **Split strategy**: Random 80/20 (no temporal split needed - all data from 2017)
2. **Stratification**: By IRI condition category (ensure balanced representation)
3. **Validation**: 5-fold cross-validation within training set
4. **Holdout test**: 20% held out for final evaluation

### Phase 5: Feature Documentation
1. Create feature metadata JSON:
   - Feature name
   - Feature type (numeric/categorical/binary)
   - Source columns
   - Transformation applied
   - Missing value handling
   - Engineering rationale
2. Save feature importance (correlation with target)
3. Create feature distribution visualizations

def calculate_metrics(y_true, y_pred):
    """Calculate all evaluation metrics"""
    rmse = np.sqrt(mean_squared_error(y_true, y_pred))
    mae = mean_absolute_error(y_true, y_pred)
    r2 = r2_score(y_true, y_pred)
    mape = np.mean(np.abs((y_true - y_pred) / y_true)) * 100
    
    return {
        'RMSE': float(rmse),
        'MAE': float(mae),
        'R2': float(r2),
        'MAPE': float(mape)
    }

def cross_validate_model(model, X, y, cv=5):
    """Perform cross-validation and return metrics"""
    scoring = {

        'mae': 'neg_mean_absolute_error',
        'r2': 'r2'
    }
    
    cv_results = cross_validate(model, X, y, cv=cv, scoring=scoring, return_train_score=True)
    
    return {
        'cv_rmse_mean': float(np.sqrt(-cv_results['test_rmse'].mean())),
        'cv_rmse_std': float(np.sqrt(cv_results['test_rmse'].std())),
        'cv_mae_mean': float(-cv_results['test_mae'].mean()),

        'cv_r2_mean': float(cv_results['test_r2'].mean()),

```python
# prediction_pipeline.py
import pickle
import pandas as pd
import json

class PavementIRIPredictor:
    def __init__(self, model_path, feature_names_path):
        with open(model_path, 'rb') as f:
            self.model = pickle.load(f)
        with open(feature_names_path, 'r') as f:
            self.feature_names = json.load(f)
    
    def predict(self, input_df):
        """
        Predict IRI for input segments
        
        Args:
            input_df: DataFrame with required features
        
        Returns:
            predictions: Array of IRI predictions (in/mi)
        """
        # Validate features
        missing = set(self.feature_names) - set(input_df.columns)
        if missing:
            raise ValueError(f"Missing features: {missing}")
        
        # Select and order features
        X = input_df[self.feature_names]
        
        # Predict
        predictions = self.model.predict(X)
        
        return predictions
    
    def predict_with_confidence(self, input_df, confidence=0.95):
        """
        Predict with confidence intervals (using tree variance)
        """
        predictions = self.predict(input_df)
        
        # Estimate uncertainty from tree predictions
        tree_predictions = np.array([tree.predict(input_df[self.feature_names]) 
                                      for tree in self.model.estimators_])
        std = tree_predictions.std(axis=0)
        
        # Confidence interval (assuming normal distribution)
        z_score = 1.96  # 95% confidence
        lower = predictions - z_score * std
        upper = predictions + z_score * std
        
        return predictions, lower, upper
```
